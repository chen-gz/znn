## [0.4.2] - 2026-11-02

### Changed

- **Optim Package Modularization (`src/optim/`) (Milestone 10.5)**:
  - Refactored monolithic 61.5 KB `src/optim.zig` into a clean, lightweight public facade and 5 single-responsibility submodules:
    - `src/optim/types.zig`: Optimizer interface, configuration types (`AdamWConfig`, `SGDConfig`), and gradient manipulation utilities (`clipGradNorm`, `clipGradValue`).
    - `src/optim/sgd.zig`: SGD optimizer with classical momentum, dampening, weight decay, and Nesterov acceleration.
    - `src/optim/adam.zig`: Adam and AdamW optimizers with first/second moment tracking, bias correction, AMSGrad variant, and decoupled weight decay.
    - `src/optim/lr_scheduler.zig`: Learning rate scheduler protocol (`LRScheduler`) and scheduling policies (`StepLR`, `CosineAnnealingLR`, `LinearLR`, `ExponentialLR`).
    - `src/optim/checkpoint.zig`: Robust binary checkpoint serialization (`saveCheckpoint`, `loadCheckpoint`) with `ZNNO` magic byte verification and parameter mapping.
    - `src/optim/tests.zig`: Dedicated optimizer and scheduler test suite.
  - Reduced `src/optim.zig` to a concise 40-line re-export facade with zero breaking API changes for callers.

- **Dataset Package Modularization (`src/dataset/`) (Milestone 10.5)**:
  - Refactored monolithic 54.9 KB `src/dataset.zig` into a clean public facade and 4 domain-specific submodules:
    - `src/dataset/dataloader.zig`: Generic `DataLoader` protocol, `Batch`, `Sampler`, and `Collate` interfaces.
    - `src/dataset/vision.zig`: MNIST/CIFAR IDX parser, Synthetic Tiny ImageNet generator, and packed binary readers.
    - `src/dataset/text.zig`: WikiText-103 causal autoregressive text stream, byte-pair encoding (`BPETokenizer`), and binary mmap dataset.
    - `src/dataset/multimodal.zig`: `MultimodalDataset`, `MultimodalPair`, and paired data loading pipelines.
    - `src/dataset/tests.zig`: Dedicated dataset and streaming tests.
  - Eliminated cross-layer tensor violations; `dataset` strictly remains in Layer 1 operating on primitive scalar slices without importing Layer 1 `tensor`.

- **Tensor Subsystem Test Decoupling & Milestone 11 Foundation (`src/tensor/`) (Milestone 10.5)**:
  - Extracted linear algebra tests (QR, SVD, SymEig) from the 130 KB monolithic `tests.zig` into `src/tensor/tests_linalg.zig`.
  - Extracted convolution and transposed convolution reference verification into `src/tensor/tests_conv.zig`.
  - Added structural placeholders `src/tensor/indexing.zig` and `src/tensor/tests_indexing.zig` with foundational error sets, ready for Milestone 11 (gather/scatter/indexing).

- **Project Root Cleanliness & Benchmark Script Hygiene**:
  - Relocated standalone Python benchmark script `examples/linear_regression.py` to `scripts/benchmarks/linear_regression.py`, ensuring `examples/` remains purely runnable Zig binaries.

- **Documentation Synchronization**:
  - Updated `doc/architecture.md` with complete directory trees and Mermaid diagrams reflecting `src/optim/`, `src/dataset/`, `src/tensor/`, `convnext.zig`, and `resnet.zig`.
