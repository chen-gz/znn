## [0.5.0] - 2026-11-02

### Added

- **PyTorch-Aligned Multidimensional Advanced Indexing & Scatter Subsystem (`src/tensor/indexing.zig`) (Milestone 11)**:
  - **`gather` & `gatherInto`**: Along axis `dim`, collects elements indexed by an integer/float coordinate tensor `index` (`dest[i][j] = src[i][index[i][j]]`). Supports arbitrary ranks (1D to 4D+), matching PyTorch `torch.gather` semantics.
  - **`scatter` & 5-parameter `scatterInto`**: Destination-driven non-allocating variant (`dest = copy(base); dest[index] = src`) and pure allocating `scatter`. Properly supports multidimensional coordinate mapping.
  - **`scatterAdd` & 4-parameter `scatterAddInto`**: In-place zero-allocation accumulation (`dest[index] += src`). Correctly handles duplicate and overlapping index entries with cumulative sum.
  - **`indexSelect` & `indexSelectInto`**: Extracts multidimensional slices along a specified axis guided by a 1D index tensor (`dest[i] = src[index[i]]`).
  - **`indexAdd` & 4-parameter `indexAddInto`**: In-place zero-allocation slice accumulation along a 1D index tensor.
  - **`maskedSelect`**: Compresses multidimensional tensors into a 1D vector at coordinates where a boolean mask is `true`.
  - **`gatherSlice`**: Slices tensors along a given axis based on dynamic run-time slice bounds.

- **Signed Strided Slicing & Negative-Step Reverse Materialization (`src/tensor/reductions.zig`, `src/tensor/types.zig`)**:
  - Refactored `SliceRange` to support signed start, end, and step (`start: ?isize = null, end: ?isize = null, step: isize = 1`).
  - Full NumPy parity for Pythonic negative step slicing (`arr[::-1]`):
    - Positive steps (`step > 0`) retain $O(1)$ zero-copy views (`is_view = true`).
    - Negative steps (`step < 0`) allocate compact reverse-ordered memory and materialize reversed elements (`is_view = false`), preventing unsigned stride underflow while ensuring complete memory safety.
  - Adapted `GenericTensor(T).slice` across generic element types and `models.gemma4_e4b` layer slicing.

- **Autograd Computation Graph Integration & Adjoint Dual Differentiation (`src/autodiff/`)**:
  - Extended `OpType` with `.Gather`, `.Scatter`, `.ScatterAdd`, `.IndexSelect`.
  - Added declarative graph APIs: `graph.gather()`, `graph.scatter()`, `graph.scatterAdd()`, `graph.indexSelect()`.
  - Extended `op.forward` re-evaluation replay for all indexing operations.
  - Implemented exact mathematical adjoint dual backpropagation in `src/autodiff/backward_math.zig`:
    - $\nabla_x \text{gather}(x, d, I) = \text{scatterAdd}(\mathbf{0}, d, I, \nabla_y)$ via zero-allocation `scatterAddInto`.
    - $\nabla_x \text{scatter}(x, d, I, \text{src})$ masks out overwritten positions to zero while preserving intact gradient components; $\nabla_{\text{src}} = \text{gather}(\nabla_y, d, I)$.
    - $\nabla_x \text{scatterAdd}(x, d, I, \text{src}) = \nabla_y$ (direct pass-through); $\nabla_{\text{src}} = \text{gather}(\nabla_y, d, I)$.
    - $\nabla_x \text{indexSelect}(x, d, I) = \text{indexAdd}(\mathbf{0}, d, I, \nabla_y)$ via zero-allocation `indexAddInto`.
  - Added finite-difference numerical gradient checking (`gradcheck`) with $\Delta < 10^{-3}$ tolerance.

- **Dedicated Unit & Regression Test Suites**:
  - `src/tensor/tests_indexing.zig`: 346 lines covering 1D-4D reverse slicing, coordinate transforms, scatter duplicate accumulation, and index selection.
  - `src/autodiff/tests.zig`: Comprehensive tests for forward value correctness, gradient routing, dual accumulation, and numerical gradchecks.
  - All 440+ unit and integration tests pass with 0 memory leaks.
  - All 18 canonical models exported successfully to JSON graphs (`zig build run-book-models`).
  - All 203 web visualizer tests pass cleanly (`npm test`).
