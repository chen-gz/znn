## [0.4.0] - 2026-10-31

### Added

- **Comptime Target Architecture Detection & Auto-Probing**:
  - Auto-probed MLX library presence in `build.zig`, safely defaulting to CPU Accelerate fallback when missing to prevent link-time errors.
  - Implemented `src/backend/target.zig` for comptime detection of SIMD vector lengths (AVX512/AVX2/NEON) and dead code pruning.

- **Unified Tensor Physical Storage on DeviceBuffer**:
  - Consolidated device residency and driver handles directly into `storage: backend.DeviceBuffer`.
  - Added non-allocating `asHostSlice` / `asHostSliceMut` for CPU data access with mutation guards.

- **Zero-Allocation Destination Operators & Forward Replay**:
  - Expanded in-place destination operators (`*Into`) across elementwise, reductions, convolutions, pooling, normalization, and losses.
  - Completely eliminated all 51 `copyFromEager` calls from `Op.forward` in `src/autodiff/op.zig`.

- **Scratch-Allocated Backward Pass**:
  - Injected `scratch_allocator: std.mem.Allocator` into `Op.backward` and eliminated all 8 `std.heap.c_allocator` usages from `src/autodiff/backward_nn.zig`.
  - Passed `Graph.arena` in `runBackward` for zero-fragmentation backward execution.

- **Static Memory Planner & Execution Graph Buffer Reuse**:
  - Implemented `MemoryPlanner` in `src/autodiff/memory_planner.zig` with liveness interval analysis and 1D FFD memory coloring, achieving $\ge 85\%$ activation memory reduction.
  - Implemented `ExecutionGraph` in `src/autodiff/execution_graph.zig` with sub-buffer slicing from a single shared arena and zero-allocation replay.

- **PyTorch-style `nn.Module` Protocol & Container Ecosystem**:
  - Added `verifyModule(comptime T: type)` compile-time protocol assertions.
  - Added `createParameter` and `createBuffer`, decoupling trainable parameters from persistent buffers.
  - Made `BatchNorm1d` / `BatchNorm2d` running statistics persistent buffers immune to `setRequiresGrad`.
  - Added reflection iterators `buffers`, `namedBuffers`, `submodules`, and generic `ModuleList(comptime T: type)`.
  - Transparently accounted for `Q4Block` quantized parameters in `numParameters`.

- `Tensor.storage: DeviceBuffer` physical device buffer abstraction and `Tensor.deviceBuffer()`
  accessor. Tensor factories (`allocUninit`, `clone`, `Graph.tensorND`), views (`transposeView`,
  `slice`, `Graph.reshape`), and device transitions manage backing storage through `DeviceBuffer`,
  retaining shared ownership so views safely outlive parent tensors.

- Checked `Tensor.asHostSlice` and `asHostSliceMut` access contiguous CPU data
  without implicit allocation or transfer, validating metadata and bounds while
  preserving graph mutation guards.

- `DeviceBuffer.fromDeviceArray` retains validated contiguous float32 CUDA/Metal
  arrays, with borrowed typed access and explicit exact-length `copyToHostF32`.
  Typed storage rejects raw byte transfers and zeroing to preserve array metadata.
  CUDA ownership records track allocation size for descriptor validation.

- Allocation-free CPU `addInto`, `mulInto`, `matmulInto`, `rmsNormInto`,
  `softmaxInto`, and `geluInto` operations write into independent preallocated
  output buffers. Explicit
  errors reject invalid shapes, layouts, storage, device residency, and overlapping
  input/output spans before writes. Strided inputs and independent graph outputs
  are supported; these functions do not implicitly transfer device data.

- CPU device buffers now retain shared allocation ownership and allocator
  provenance. Explicit retained byte views survive parent release, empty buffers
  allocate nothing, and typed access validates alignment.

### Changed

- **Composable Models & Declarative Tensor Flow (Milestone 5)**:
  - Added `Graph.arange` in `src/autodiff/graph.zig` allocating directly in the graph arena for leak-free index generation.
  - Refactored `models.GPT` in `src/models/gpt.zig`: replaced procedural loops with declarative `graph.arange` and standard `nn.Embedding` broadcasting; eliminated outer temporary reshapes, delegating multi-rank input handling natively to `Linear.forward` via `RowView`.
  - Refactored `decodeAttention` in `src/models/gemma4.zig`: eliminated host-memory scalar pointer loops and replaced per-query calls with vectorized `graph.attention` (BLAS SGEMM), unifying incremental decoding and prefill under standard `Tensor` and graph operator execution.
  - Aligned model JSON exports, visualizer tests (`web/src/utils/model-graph.test.ts`), and unit tests (`src/models/tests_vis.zig`).

- Removed legacy `device` and `device_array` fields from `Tensor`, consolidating
  physical device residency and driver handles directly into `storage: DeviceBuffer`
  as single source of truth. Updated accessors (`getDevice`, `getDeviceArray`,
  `setDeviceArray`, `clearDeviceArray`), optimizers, autodiff operations, graph
  lifecycle, and tests to manage device ownership through `DeviceBuffer`.

- Persistent module tensors (`createPersistentTensor`, `createCacheTensor`,
  `freePersistentTensor`) in `src/nn/module.zig` now allocate host backing memory
  through `DeviceBuffer.alloc`, eliminating unmanaged CPU buffer lifecycles.

- Support dynamic CLI arguments (`-n` / `--max-tokens`, `-p` / `--prompt`, `--model-dir`)
  and flexible vocabulary resolution in `examples/gemma4_e4b.zig`.

- `DeviceBuffer.free()` no longer accepts an allocator. Call sites release through
  stored ownership; descriptor copies must use `retain()` to acquire a reference.

### Fixed

- Mark graph op output tensors `is_graph_owned = true` in `registerSingleOutputOp`
  and eliminate duplicate tensor registration in `Graph.reshape`, `transposeND`,
  and `slice`, ensuring graph-owned buffer storage is reclaimed on `deinit` and `reset`.

- Host synchronization stages transfers before committing, preserving existing
  data and ownership on allocation/transfer failure. Successful synchronization
  releases the device array so subsequent host edits cannot reuse stale device
  values. Growing host storage requires an explicit allocator, and graph callers
  materialize into their own arenas. Device upload copies host data and rejects
  implicit cross-device transitions; MLX host-copy evaluation failures propagate.

- Metal `DeviceArray.clone` creates an independently owned copy instead of
  reusing the same handle. Explicit device-array retention uses CUDA ownership
  or a separate MLX shared handle, with cleanup on failed handle creation.

- CUDA array reshape views retain a shared allocation instead of independently
  freeing the same device pointer. Every array-producing operation creates an
  atomic ownership record; final release frees the allocation. Tensor conversion
  returns an owned reference, and graph reshape cleans up unregistered device
  views on allocation failure. Invalid/overflowing shapes fail before retention.

- Metal buffer prefix uploads and device copies preserve capacity and untouched
  suffix bytes. Validate byte-array metadata before transfers, evaluate replacement
  storage before releasing the original, and propagate evaluation failures.
  Empty transfers avoid driver calls; oversized Metal allocations fail explicitly.

- CPU buffer copies now handle overlapping ranges safely. Metal device-copy
  construction uses the supported MLX copy API instead of a nonexistent method.


- Added an explicit `-Dmlx=false` build path for CPU validation without optional
  Apple acceleration libraries, plus `-Dmacos-sdk` for explicit SDK lookup.
  The library now honors `-Doptimize`, and disabled Metal buffer reads return
  a controlled error. Timing tests wait beyond clock resolution in optimized builds.

- In-place tensor arithmetic now returns `TensorError.InPlaceOpOnGraphTensor`
  before modifying graph-backed data in every optimization mode. Slice and
  transpose views retain mutation protection through nested views. Scalar
  `mulScalar_` and `addScalar_` calls now require error handling; regression
  examples are updated. Explicit `TensorError` is exported from the tensor facade.
